# 围棋音效来源

- `place.wav`：Kenney 的 Casino Audio 1.1，原文件 `chip-lay-1.ogg`，裁去开头约 41 毫秒的空白。
- `capture.wav`：同一素材包的 `dice-grab-1.ogg`，裁去开头约 180 毫秒。
- 作者：Kenney（https://kenney.nl/）；素材页：https://kenney.nl/assets/casino-audio
- 授权：Creative Commons Zero 1.0（CC0），https://creativecommons.org/publicdomain/zero/1.0/
- 获取：从公开镜像 https://github.com/latent-spaces/brag/tree/669ab9286aa28b6c3ee30e75f181ee74319d012a/skills/brag/assets/sfx/casino 获取原始文件，以 libsndfile 转为 16 位 PCM WAV，方便各浏览器播放。
