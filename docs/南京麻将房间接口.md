# 南京麻将房间接口

本文件描述阶段 2 服务端接口。网页麻将桌、正式麻将本地策略和大模型决策分别属于后续阶段。所有接口均为同源 POST JSON，返回现有 `{ok,data}` 或 `{ok:false,error,code}` 格式。

## 房间与座位

- `/api/room/create`：传入已登录账号的 `uid`、`me`、现有线上建房码和 `cfg: {mode:'online',gameType:'nanjing',initialSeeds:100}`。可选 `dealerSeat:0..3`，省略时随机首庄。响应中的 `seatId`、`seatToken` 是座位凭证，应保存在客户端私有存储，不放入 URL。
- `/api/room/join`：其他已登录用户携 `uid`、`roomId`、`me` 入座；原座位重连需同时提供原凭证。最多四席，开场后不接纳新座位。麻将房间不会通过仅提供设备 uid 补发已有座位凭证。
- `/api/room/add-ai`、`/api/room/remove-ai`：房主凭证操作；限本场开局之前，AI 自动准备。
- `/api/room/state`：凭有效 `seatId` 和 `seatToken` 获取本人视角，无凭证为旁观者。对局中投影只含本人 `myHand` 和 `myActions`，不含牌墙顺序、其他玩家暗牌、未裁定响应或座位凭证。无自己的可选动作时 `myActions` 为空；本手结束状态中所有视角额外获得按座位排列的 `revealedHands`（包括重连），网页展示约1秒后进入仅展示胡家的结算页面；下一手开始后不再返回。
- 新手的 `wallLayout` 公开两颗骰子、开墙座位和墩位、墙头与墙尾已取张数以及四家每墩剩余的 0/1/2 张，均不包含牌值。庄家自动掷两颗骰子，庄家计 1、按点数和逆时针数座位，在该家牌墙留较小骰子点数的墩数，从下一墩开始顺时针取牌。每家四张发三圈，最后庄家两张、其他人各一张；随后按庄家起逐家自动补花，补花和杠补从墙尾，出牌回合按逆时针。旧快照保留原有记录；没有开墙记录时不猜测位置，下一手恢复显示。
- `/api/room/list`：麻将房返回 `gameType:'nanjing'` 和 `maxSeats:4`，邀请可沿用房间号；其他玩家需通过正常入座流程获得自己的凭证。
- `/api/room/leave`：房主明确离开时移交在场真人；进行中的原座位由本地托管完成。最后一名真人离开关闭房间，保存已完成或中止时的本场流水；临时断线不等于离开。

## 准备和行动

下列请求除字段外均须带 `uid`、`roomId`、`seatId` 和 `seatToken`：

1. `/api/mahjong/ready`：传 `matchId`、`handId`，可选 `ready:false` 取消准备。每手后真人重新准备，AI 自动准备。
2. `/api/room/start`：房主传当前 `matchId` 和 `handId`；四席已准备才开手。下一手同样由房主开始。
3. `/api/room/action`：传当前 `matchId`、`handId`、`windowId` 及 `action`，动作从本人最新 `myActions` 中选择。示例：`{type:'discard',tile:'1m'}`；碰杠胡等以服务器实际返回列表为准。同一响应窗口中其他人已提交不影响本人使用该窗口号；自己的重复提交、旧手或旧窗口会被拒绝。
4. `/api/mahjong/reset`：整场结束后，房主传当前 `matchId`、`handId` 开新场；场次标识更换，旧战绩保留，真人重新准备。此接口不修改账户金瓜子。

服务端控制出牌 30 秒、报听/响应 15 秒，截止时间为 Unix 毫秒。超时或已离开的座位以及 AI 均使用阶段 3 的[麻将本地策略](南京麻将AI本地策略.md)选择合法动作；阶段 5 的模型尚未接入。刷新、断线和转屏不重置牌局。

## 保存和恢复

麻将快照与完成手的战绩在同一 SQLite 事务内写入；战绩按场次和手号去重，实际流水每笔有稳定标识。快照包含服务端必需的牌墙、手牌和座位认证材料，只能留在服务器数据目录；不能把完整快照返回网页或写入普通日志。恢复先核验牌张和响应窗口，再按原截止时间重新挂载计时器。最后一名真人离开或房间闲置回收时，未完成手按中止结果保存实际流水，不公开非胡家手牌。

真人座位在入座时固定账号归属并保存到快照；之后退出登录或设备改登其他账号不会改变该座位的战绩归属。旧版本快照如果没有保存入座账号，无法从后来可变的设备登录状态可靠还原，恢复后该座位归属记为未知，不自动归给设备当前账号。清理过期快照与普通房间历史时保留麻将战绩，即使房号已被其他玩法复用。
