# 南京麻将本地策略 v2.2

本版本仍只读取自己手牌和公开观察，输出必须来自引擎提供的合法动作。原 v1 基线保留不变，v2.1 参考代码单独保留；规则、房间协议和实际结算未改。本次为待审候选，不自动发布。

策略将每种出牌、过牌、碰、直杠、暗杠和补杠构造成独立候选：转移公开牌后重新统计可见张，碰后逐种计划弃牌但不提前提交；花牌和未知补牌不凭空增加。碰或直杠成功时按公开副露的来源次序计算第三嘴责任，补杠只更新已有碰，暗杠不计嘴，已有绑定不改；来源缺失时显式标未知，并比较可能的绑定付款而不猜造来源。

结构距离为零不代表已有合法听张。当前合法完成张、硬花资格缺口和已经耗尽分别记录。没有合法未见胡张时，仍可通过后续换牌或补花恢复，但现时没有假设胡款、完整听牌速度分和旧路线连贯奖励。对实际能成立的大胡及已满足资格的小胡继续按真实规则计分。

进张项为 `10.5 × (1 − exp(−n/30)) / (1 − exp(−1))`，单位是策略内部排序分，上限约 16.61；在 30 张时为旧版的 10.5 分。它连续递增、边际递减，不是胡牌概率。速度每距离 7 分、未来参考收付权重 0.42、风格偏移、随机温度 0.4、近分范围 0.75 及 v2.1 的严格劣势过滤均未调整。

碰、直杠、补杠的成功状态是条件分支；成功杠款单独记录，不作为无条件即时收益。条件收益及成功后未来参考收益以 0.65 的启发式系数计分，并结合基于公开报听、副露及剩余牌数的有上限不确定性成本；这些数字均不是事件概率。补杠被抢分支没有杠款、补牌和完成后的补杠副露，实际付款由权威结算规则决定。成功后若立即结束整场，不计算后续胡牌收益。

仍然不知其他玩家暗牌、实际牌墙和未来响应，因此付款参考不是预期真实收益，风险和折扣均需进一步检验；没有增加下一层搜索或推断真实胜率。生产预算依旧是策略 500ms、最多两个线程、线程外 700ms，以及 35ms 基础回退；结果返回时仍复核房间、手号、窗口和合法动作。策略诊断沿用私有复盘，不进入公开状态。
