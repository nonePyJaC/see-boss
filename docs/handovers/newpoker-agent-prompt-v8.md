# poker-facts-v8：价格合理时买牌与主动取值

## 改动

- 固定system从2086字符、31行重组为1558字符、16行，减少25.3%；这是字符数，不是供应商token计量。
- 明确价格、听牌质量及权益实现支持时应考虑call买牌；不因尚未成牌、非坚果或可能后续收费就自动弃牌。区分翻牌普通跟注看下一张、已付清后续费用时看到河牌的机会，保留隐含/反向隐含赔率与补牌质量判断。
- 价格合适也不强制跟注。强牌先比较价值下注收益，有利听牌可考虑半诈唬；check需具体范围、风险或诱导收益。
- 自身近8手只作形象/风格参考，不能用过去常弃证明现在该弃。要求每次明确nextStyle，保持时也填写当前枚举；base仍是各AI原有基础人设。
- 动态局面补充公共牌花色计数，仅统计公共牌；零跟注成本使用中性事实“本次跟注成本0”。原完整历史、付款义务、对手状态、牌力/赔率事实和合法动作均保留。

## 边界

产品代码只改server/ai/llm.mjs的固定system和server/ai/prompt-facts.mjs的事实表述。模型、Key接入、参数、预算、超时、解析器、回退、引擎、调度、数据目录与7天私有记录均保持。没有新增自然语言关键词硬校验、重试或持久化计划，不进行付费模型调用。

模型是否在真实对局中更合理地买牌、取值或变换风格，仍需自然试玩确认；构造输入与模拟输出不能证明真实模型行为已改善。已知引擎收街问题继续独立保留，本次未修复或关闭。

完整固定system与匿名价格示例见[提示词v8](../AI提示词v8.md)。发布继续使用根AGENTS规定的固定完整SHA唯一流程。
