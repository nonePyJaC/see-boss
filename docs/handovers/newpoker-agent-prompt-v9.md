# poker-facts-v9：统一范围与收益比较

## 设计

以同一决策框架替换泛化的策略段：公开事实与当前响应→对手范围→合法动作的预期收益→随新信息调整路线。

- 同时考虑对手强牌、较弱成牌、听牌和诈唬；范围与反应是推测，不当作已知私牌。
- 下注/加注考虑谁以较弱牌支付、谁以更强牌继续、谁可能弃牌；跟注比较可赢范围与价格；check考虑摊牌和诱导收益。
- 当前圈的待响应决定后续机会；过去慢打、主动进攻或风格都不锁定当前路线，预期的支付/下注未发生时重新评估。
- 保留价格合理时买牌、实际权益与成牌概率区别、风格自主选择、合法性与私牌边界；不新增特定牌型强制下注、随机动作或理由禁词判废。
- 固定system与v8均1558字符；动态USER和完整历史逐字不改。只改一个产品文件server/ai/llm.mjs的system块，其他产品代码不变。
