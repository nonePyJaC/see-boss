# 结算后重置开局与AI自身打法（v7）

## 用户行为

- 每手结束后，房主结算页均显示「重置筹码并开局」，无须等到全桌只剩一人有筹码。
- 一次点击把所有仍在座的人恢复为建房时初始筹码，并按原牌型、盲注、模型设置直接开始下一手。真人座位、令牌和账号保留，输光的玩家重新发牌。开局后的筹码已扣除本手盲注。
- 「开始下一手」仍保留原筹码继续；重置会清空房间最近手牌与AI运行历史，沿用原先重置逻辑重新生成AI基础人设，不改账号、个人模型Key或账本。
- 服务端验证房主令牌、两手之间和当前handId；连点/过期结算页不能重置已经开始的新手。旧版不带立即开局选项的重置请求仍返回等待开局状态。

## 提示词与状态

版本 `poker-facts-v7`，保留v6牌力/对手行动优先级、完整本手公开历史、上一手一句公共结果与稳定system前缀。

新增个人动态摘要示例（构造数据）：

```text
【我的近8手打法】近8手：弃6、连弃4；翻前自愿入池2；下注/加注1、跟注3、过牌4；面对下注6次弃5。
【我的性格】仅作边缘选择参考：偏主动争取底池（当前pressure）
```

可选输出示例（只示范字段，不代表真实模型输出）：

```json
{"action":"raise","amount":120,"reason":"对手范围含可弃的弱牌，选择小额半诈唬","nextStyle":"pressure"}
```

风格枚举为base、balanced、pressure、patient、tricky；不输出则延续。只在模型动作实际采用后保存到当前房间的该AI，下次输入显示新风格，允许再回base。不保存自由文本计划，不更改本地策略和模型参数。连弃可以考虑变线，但不能自动推断对手倾向或强制诈唬。

自身统计只计最近8手已完成牌局的实际动作，当前手仍使用完整行动历史；跨手延续，重置/离房清空，不落数据库。变更提议与实际生效结果只写原7天私有复盘，公开状态及普通日志不暴露。
