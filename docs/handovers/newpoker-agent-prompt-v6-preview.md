# 提示词v6：两手预览待用户确认

基线：`415e21fc59504f191edca23fca76e993e291d2f4` / `poker-facts-v5`。
本地代码：`poker-facts-v6`。本交接随本轮功能提交，完整SHA见交付回执。

## 用户要求与实现

- 人设弱化为辅助偏好，移到局面事实之后。优先牌力、对手公开行动与范围、价格/位置/有效后手；不改人设生成参数，也不强行增加跟注或加注频率。
- 补踢脚来源、超对；分析对手时不把下注当成必有强牌。慢打、控池、继续或弃牌需有具体依据，河牌不套用免费看下一张的理由。
- 只取最近一手的一句公共结果，不扩observation或跨手统计。不附上一手公共牌/流水；未摊牌不猜牌型，明确分池额与退款，避免把分池额当净赚。
- 本手完整公开历史、固定座号、逐字追加缓存结构保留；模型、温度、token预算、超时、Key接线、输出JSON、日志、本地策略与引擎不改。

## 两手示例

[预览说明](D:/newPoker/docs/AI提示词v6两手预览.md) · [交互页面](D:/newPoker/docs/examples/prompt-v6-preview.html)

1名玩家＋2名AI，盲注50/100，初始各5000，第二手承接筹码并轮转按钮；固定牌堆和人工指定动作，17个AI请求，不进行抽样或模型调用。

- 第一手：稳健AI甲持同花KQ，顶对后成两对逐街取值；主动AI乙听顺落空河牌弃牌。AI甲摊牌胜玩家，分池6850。第二手仅带这句公共结果。
- 第二手：AI甲持JJ，翻牌超对跟注、转牌取值，河牌A出现后按新局面抓诈，最终输给玩家的A对子；不把输掉底池当作自动判错。AI乙转牌弃牌，不再收到河牌请求。

模型输入由实际`buildMessages`与安全observation生成；页面顶部全桌底牌仅供审阅，每条user只包含该AI私牌。所有输出明确标为人工示范，不宣称模型已经表现改善或某条路线唯一正确。

生成：`node docs/examples/build-prompt-v6-preview.mjs`。
对同一17个观察比较v5/v6：固定system字符2042→1912，总输入字符54209→52472（减少3.20%）；未使用供应商tokenizer，不能当作token、成本或缓存命中保证。
