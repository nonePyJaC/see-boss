# 一手围棋 · 网页级位训练

入口：`http://8.133.3.206/go-training/`。这是现有80端口站点下的独立子应用，不修改8080 Wiki，不开新公网端口或新增PM2应用。

## 发布

代码位于 `client/public/go-training`，由现有Vite构建复制到同一release的 `client/dist/go-training`。云同步由 `server/go-training.mjs` 提供，唯一接口为 `POST /api/go-training/progress`。

遵守根目录AGENTS.md：先提交并推送到 `feature/room-repo`，再运行 `npm run deploy:ecs -- <完整40位SHA>`。状态使用 `npm run deploy:ecs -- --status`；回滚使用同一发布命令指定之前发布的SHA。不得直接覆盖服务器文件或手动改PM2。

数据使用既有 `/var/lib/cangshu/hamster.db` 内独立的 `go_training_progress` 表；仅首次同步时创建，不改动账号、Key、账本、房间表。同步码192位随机，仅在服务端保存SHA256摘要；同源接口、版本比较更新、冲突时由用户选择。每个请求8MiB上限，IP限流，最多64个云存档。运行密钥不进入本项目，也不记录同步码或进度请求体。

默认IndexedDB本机保存，异常环境回退localStorage。云同步是可选的：同一同步码可在电脑和平板继续；冲突保留本机与服务器备份，不静默覆盖。当前服务器只有IP+HTTP，没有TLS，不宣称同步码具备传输加密。网页不要求仓鼠聚会账号，不接入模型服务。

## 功能与原版依据

- 原始六个题库的6124条题面、361格初始棋子与7356条非空答案变化，原谱共23056手。
- 原版顺序练习每档1000题；网页到第1000题可进入下一档。额外124题仍可从题号列表选择，标记为拓展题。
- 八个动物练习书签、最多五位具名受测学员、各级位累计次数、名单管理、音效及两首原版音乐。
- 原版每轮10题、每题10分，六档评分表由旧exe `0x403850` 及相关只读数据提取，见 `legacy-rules.mjs` 及 [原版规则核对](围棋训练原版规则核对.json)。最低档30/29级分数区间重复，按原版首次匹配保留原结果，不擅自改成新算法。
- 证书按学员与达到的级位累计：>=5银质、>=10金质。旧文案“连续”与执行代码不一致，网页按代码的累计语义显示。
- `gosave.dat`：8×16字节书签（档位、零基续题号、答对计数、奖励计数），int32学员数0..5，20字节GBK姓名数组，31×int32级位计数数组；总长度132+144×学员数。导入保留两个原计数器；旧文件没有具体答题记录和考试日期，不伪造已掌握题号或历史证书日期。
- 九条原谱劫争变化省略劫材，自动应手按原谱展示并提示；自由落子禁止立即回提。四条初始局面超出13路区域，显示完整19路。
- 新增确认落子、触屏与键盘操作、多分支逐手播放、提示悔棋、错题收藏、自动保存恢复、进度导入导出、服务器同步与证书SVG下载/打印。训练证书不是棋协正式认证。
